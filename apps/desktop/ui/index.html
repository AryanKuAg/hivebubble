Hivebubble

Talk to your website, watch the hive build it.

v0.1

Open a project

Choose the folder of a web project (Next.js, Vite, Astro, …). Hivebubble installs what it needs, starts it, and adds the chat bubble to the page.

Start something new

Say what you want to build. Hivebubble picks a starter, copies it into a new folder, starts it, and puts your request in the bubble for Claude.
